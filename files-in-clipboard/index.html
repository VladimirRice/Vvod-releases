Файлы в буфере обмена

Vvod переносит между вашими устройствами не только текст и картинки, но и небольшие файлы: отправили файл с телефона — он появился в буфере на компьютере, и наоборот. Передача идёт через вашу папку в облаке и шифруется так же, как остальные записи.

Как файл попадает в буфер

  • Телефон: откройте файл в любом приложении и выберите «Поделиться» → «Vvod». Так же работает «Поделиться» из проводника и из галереи.
  • Компьютер: скопируйте файл в проводнике — Vvod подхватит его так же, как скопированный текст.

Что можно делать с записью-файлом

  • Открыть — файл открывается приложением, которое выбрано в системе для этого типа.
  • Сохранить как… — файл сохраняется туда, куда вы укажете. При сохранении Vvod показывает размер: так видно, что файл записан целиком.
  • Поделиться — на телефоне открывается системная панель отправки, на компьютере файл кладётся в буфер обмена и показывается в проводнике.

Размер и типы

  • До 5 МБ файл уезжает на ваши другие устройства; больше — остаётся на этом, и Vvod говорит об этом сразу.
  • Хранить в буфере можно файлы до 20 МБ.
  • Исполняемые и служебные типы не принимаются вовсе: .exe, .msi, .apk, .bat, .cmd, .ps1, .vbs, .js, .lnk, .dll, .sys, .jar и подобные. Буфер обмена — не место для запуска чужого кода.

Видно, сколько уже скачано

Рядом с записью-файлом показано состояние: «0 из 2,0 МБ · ещё не скачан», «скачивается…», «2,0 МБ · скачано». Под списком — итог по всем вложениям: «Вложения: 3 из 5 · 4,0 из 8,5 МБ (47%)».

Запись и её файл приходят разными кругами синхронизации: сначала появляется сама строка, а байты догоняют. Ускорить можно кнопкой обновления списка (↻) — Vvod подсказывает её в сообщении о записи, файл которой ещё не скачан.

Фильтр по типу записи

Над списком есть выбор: «Все / Текст / Картинки / Файлы». В режиме выбора «Выбрать все» берётся ровно то, что показано фильтром, — так удобно убрать накопившиеся вложения.

Чего не делаем

Публичных ссылок на файл Vvod не выдаёт: файл передаётся только между вашими устройствами через ваше облако. Запись-файл, как и картинку, можно оставить только на этом устройстве — галочкой «только на этом устройстве».
