Синхронизация между телефоном и компьютером — без сервера разработчика

Vvod синхронизируется через вашу папку в облаке. Своего сервера у Vvod нет.

Как это устроено

  • Подключение — Яндекс.Диск по API или любой WebDAV.
  • Содержимое (буфер обмена, шаблоны, заметки, пароли) шифруется мастер-паролем до отправки: в облако уходит шифротекст.
  • Мастер-пароль знаете только вы. Мы его не получаем и восстановить не можем — забытый мастер-пароль восстановлению не подлежит.
  • Без шифрования передаются только служебные данные: имя устройства, платформа, время обмена и несколько общих настроек. Так список устройств работает и при запертом хранилище. Владельцу облака видны также число и размер файлов и время обмена.
  • Устройство можно убрать из списка командой «Забыть устройство».
  • Условия хранения в облаке определяет его владелец (например, Яндекс), а не мы.

Что важно знать

  • Синхронизация включается вами и работает только в вашу папку.
  • Без неё приложение работает полностью офлайн.
  • Офлайн-режим отключает синхронизацию одним переключателем.
