# Vvod — сборки

Помощник ввода текста: диктовка, буфер обмена с историей, шаблоны и сокращения, пароли с
автозаполнением, горячие клавиши, переключение раскладки. Windows и Android.

Работает офлайн. Синхронизация между своими устройствами — через **ваше** облако (Яндекс.Диск или
другой WebDAV); наших серверов в этой схеме нет.

Здесь лежат только готовые файлы. Исходный код — в закрытом репозитории.

## Скачать

**[Последняя версия](../../releases/latest)** — оттуда нужен один файл:

| | файл | размер |
|---|---|---|
| Windows | `Vvod-x.y.z.msi` | ~140 МБ (внутри офлайн-модель распознавания речи) |
| Android | `Vvod-x.y.z.apk` | ~45 МБ |

## Установка на Windows

1. Скачайте `.msi` и запустите.
2. Windows, скорее всего, скажет **«Неизвестный издатель»**, а SmartScreen может перехватить
   запуск: наши файлы не подписаны сертификатом издателя. Нажмите «Подробнее» → «Выполнить всё
   равно». Антивирус тоже может спросить.
3. Права администратора **не нужны** — программа ставится в ваш профиль пользователя.
4. После установки Vvod живёт значком у часов (в трее), собственного окна при запуске не
   показывает. Значок может быть спрятан под стрелкой «Показать скрытые значки».

Горячие клавиши по умолчанию: **Ctrl+Alt+B** — буфер обмена, **Ctrl+Alt+K** — шаблоны,
**Ctrl+Alt+P** — пароли, **Ctrl+Alt+D** — диктовка.

## Установка на Android

1. Скачайте `.apk` и откройте его.
2. Android спросит разрешение на установку приложений из этого источника — разрешите. Это
   спрашивают один раз.
3. Новая версия ставится **поверх** прежней: данные и настройки остаются на месте.

## Обновления

Дальше эта страница не нужна. **Настройки → Обновления** в самом приложении: там видно
установленную версию, кнопка проверки и список изменений. Vvod проверяет сам при запуске (не чаще
раза в час) и, если версия новее, показывает сверху полоску «Доступна версия …» — без всплывающих
окон. Скачанный файл сверяется по контрольной сумме, так что недокачанный или подменённый не
установится.

Автопроверку можно выключить в том же разделе.

## Ваши данные

Всё хранится на вашем устройстве. Синхронизация включается по желанию и ходит в папку, которую вы
укажете сами. Записи в облаке зашифрованы мастер-паролем, который знаете только вы — **и который
нельзя восстановить**: забыли его — зашифрованное не прочитать никому, включая автора программы.

## Проверка файла (по желанию)

Контрольные суммы SHA-256 напечатаны в описании каждого релиза. Проверить в Windows:

```
certutil -hashfile Vvod-x.y.z.msi SHA256
```
